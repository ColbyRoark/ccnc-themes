# Installing themes

[← Back to README](../README.md)

You need [ccNC for Gen5W](https://github.com/JacobPantuso/ccnc-gen5w) installed on the head unit.

## From the Theme Store (Wi-Fi)

1. Connect the head unit to a Wi-Fi network with internet access (a phone hotspot works).
2. Open **Settings > Screen Theme > Theme Store**.
3. Choose a theme to see its preview, then tap **Install**.
4. Tap **Use**, or choose it later in **Settings > Screen Theme > ccNC Theme**.

Every ccNC app switches the next time it comes to the front.

## From a USB stick

1. Download `ccnc.theme.<id>-<version>-nemesis.zip` from the
   [latest release](https://github.com/JacobPantuso/ccnc-themes/releases/latest).
2. Unzip it onto the root of a FAT32 USB stick.
3. Plug it in and install the theme from **NEMESIS Manager > Package Store**.
4. Choose it in **Settings > Screen Theme > ccNC Theme**.

## Updates

When the head unit joins Wi-Fi, ccNC checks for new themes and updates and shows a notification.
**Nothing installs by itself**: open the Theme Store and tap **Update**.

## Removing a theme

Open the theme in the Theme Store and tap **Remove**, or uninstall its package in NEMESIS Manager if you
installed it from USB. If it was in use, ccNC goes back to **ccNC Nebula**.

## Kia and Hyundai

Some themes are made for one brand. The store and theme list only show themes that fit your car.
